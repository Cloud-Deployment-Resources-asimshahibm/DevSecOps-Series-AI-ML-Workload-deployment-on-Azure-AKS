Flow
① Terraform builds VNet, AKS (+NAP, AGIC), Blob/Files/PostgreSQL, Key Vault, Argo CD
② CI (OIDC) builds, scans, pushes to ACR; bumps tags in Git
③ Argo CD syncs every component from Git (Helm)
④ Users reach the model API and JupyterHub via the App Gateway
⑤ Argo Workflows runs Ray Tune on KubeRay (CPU/GPU)
⑥ Gated model registered + promoted in Blob (az://)
⑦ Inference pods hot-reload the promoted model
⑧ Metrics/logs → Prometheus, Loki, ELK; SLO + cost rules
⑨ Grafana adds Azure Monitor; budgets + anomaly alerts
